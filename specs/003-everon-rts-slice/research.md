## 2026-10-29 corrections
Decision: use existing deadline and explicit paid-ready state for building inventory; placement validation no longer checks purchase credits. Rationale: orders are paid before placement and survive cursor cancellation. Alternative rejected: spawn hidden real building while producing (unnecessary simulation ownership).
Decision: unscheduled init.sqf uses existing RunInitScript synchronous path. Current init.sqs sleeps0.5s and necessarily exposes first-person camera. No delay/black-screen workaround.
Evidence CI40766209520: Windows compiled but minidump exception regression failed with0x800706F8; both macOS builds/Foundation passed, Rust lifecycle test reads Linux-only/proc and falsely reports freshly spawned sleep absent. Preserve platform jobs and fix observed cause.

Windows dump decision: serialize MiniDumpWriteDump on a dedicated local writer while the faulting thread waits and retains the original exception pointers/thread ID; fallback/strict context checks remain. This follows [Microsoft guidance](https://learn.microsoft.com/en-us/windows/win32/api/minidumpapiset/nf-minidumpapiset-minidumpwritedump). CI root cause remains an inference until the new native run: local pre-fix10/10 already passed, CI alone reproduced ERROR_INVALID_USER_BUFFER. New strict local regression verifies original thread ID, code, sentinel argument, context bounds and instruction address.
Native startup validation exposed raw Execute not accepting leading // in init.sqf: keep init.sqf as executable expressions and comments in its compatibility stub/session.sqf. No engine parser changes in this slice.
