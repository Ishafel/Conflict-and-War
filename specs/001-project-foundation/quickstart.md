# Quickstart: Основа Conflict & War

1. Для разработки по SDD используйте [памятку Spec Kit](../../docs/sdd/README.md).
2. Для компиляции используйте [Windows/macOS инструкции](../../docs/building.md).
3. Для продолжения этой функции укажите агенту
   `SPECIFY_FEATURE_DIRECTORY=specs/001-project-foundation`.
4. Посмотрите [tasks.md](tasks.md) и [verification.md](verification.md):
   нативные build/test остаются открытыми до реального запуска.
