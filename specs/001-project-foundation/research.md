# Research: Основа Conflict & War

## Решение: официальный GitHub Spec Kit

Выбран Specify CLI 1.2.3 из официального PyPI-канала, подтверждённого
[документацией установки](https://github.github.io/spec-kit/installation.html).
Инициализация существующего проекта выполнена штатным init, с локальной резервной копией.
Самостоятельные SDD-шаблоны исключены по указанию владельца.

## Решение: codex + Python scripts

Штатная интеграция устанавливает навыки в .agents/skills/.
Python >= 3.11 обеспечивает один вариант вспомогательных скриптов для Windows/macOS.
При генерации Python должен быть на PATH: иначе CLI может вставить локальный путь.
Регенерация с Python на PATH устранила этот случай без модификации upstream-шаблонов.
Официальные manifests используются для проверки целостности установки.

## Решение: сохранить текущий стек

Основание — требование владельца и ADR-0001. Доказанного тупика для смены стека нет.
Нативные сборки ещё не подтверждены; инструменты и SDK устанавливаются по docs/building.md.
